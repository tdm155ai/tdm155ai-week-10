Each page has the same parts: **what it is** (and what it costs), **the maneuver** unpacked step by step, **videos** with what to watch for and when, and **a prompt** you can paste into Claude Code to build a version of the maneuver in about 20 minutes, firing cues on this app's stage.

| App | Mechanic | Free to try? | Build a version today? |
| --- | --- | --- | --- |
| [QLab](/pro-apps/tools/qlab) | cue list | yes, limited (Mac only) | yes |
| [TouchDesigner](/pro-apps/tools/touchdesigner) | node graph | yes, non-commercial | partly |
| [Isadora](/pro-apps/tools/isadora) | node graph + cue list | demo, no saving | yes, its core |
| [Resolume](/pro-apps/tools/resolume) | clip launching | demo, watermarked | partly |
| [MadMapper](/pro-apps/tools/madmapper) | projection mapping | yes, watermarked | partly |
| [Millumin](/pro-apps/tools/millumin) | cue list + mapping | 30-day trial (Mac only) | partly |
| [Ableton Live](/pro-apps/tools/ableton-live) | clip launching | 30-day trial; Lite with controllers | partly |
| [Max/MSP](/pro-apps/tools/max) | node graph | 30 days, then no saving | partly |
| [ETC Eos and grandMA3](/pro-apps/tools/eos-grandma) | lighting console | yes, offline software | no (for real lights) |
| [disguise and Notch](/pro-apps/tools/disguise-notch) | media server | Starter free; Notch 60-day trial | no |

TouchDesigner, Isadora, and Blender will be open in class to show the graphical side.
